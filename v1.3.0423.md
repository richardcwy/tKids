# v1.3.0423 — 本日觀星 (Today's Stars)

**Released:** 2026-04-23
**Branch:** main

## What changed

### New: 本日觀星 fortune draw
- `apps/web/src/pages/stargazing.astro` + `/en/`, `/ja/`, `/de/` variants
- `apps/web/src/components/FortuneDraw.astro` — self-contained island
- `apps/web/src/data/fortunes.ts` — 15 hand-written cards across three
  tiers (super / very / lucky), two voices (playful + mystical), four
  locales each, tagged to specific members (Ethan / Alan / Albert / random)

### How the draw works
- Three face-down cards fanned on a starfield. User taps one.
- Weighted tier pick: 10% super, 40% very, 50% lucky. Within-tier picks
  are uniform — adding a card to a tier rebalances automatically.
- Chosen card lifts, flips, fades. Reveal card slides in with tier badge,
  member-colored aura portrait, fortune body, lucky color / number /
  track / member.
- GA event `stargazing_draw` fires with `tier`, `fortune_id`, `voice`, `member`.
- Daily cap: `localStorage["tkids:stargazing:v1"] = { date, id }`. Same
  calendar day replays the saved pull with the animation skipped. Next
  calendar day clears and allows a fresh draw.

### Share
- Navigator Share API on mobile; `navigator.clipboard.writeText` fallback
  on desktop with a toast. Share text interpolates the tier the user drew.

### Nav
- `nav.stargazing` key + localized label added to all four i18n JSONs
  (`本日觀星` / `today's stars` / `今日の星占い` / `Sterne des Tages`)
- Gold link with a pulsing `✦` glyph so it reads as the "fun" entry,
  not another section anchor.

### Accessibility
- Respects `prefers-reduced-motion: reduce` — draw works instantly with
  no animation.
- `aria-live="polite"` on the reveal card so screen readers announce the
  fortune once it lands.

### Why this exists
- Daily-return mechanic for fans waiting on the crowdfunding launch.
  Positive-only tiers (no "unlucky") — this is fan service, not tarot.
- Static JSON + client RNG. No server, no DB. Good enough for MVP; if
  we later want streaks or member-bias from profile, port to an oRPC
  endpoint reading from Turso.

## Out of scope
