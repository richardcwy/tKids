# v1.2.0421 — shooting stars, teaser banner, global marquee

**Released:** 2026-04-21
**Branch:** main
**Previous:** v1.1.0420-beta1

## What changed

### New: ShootingStars
- `apps/web/src/components/ShootingStars.astro`
- Fixed full-viewport overlay. Spawns one star every 3–8 seconds, travels
  600–1000px at ~30° below horizontal over 1.1–1.7s, then removes itself.
- Respects `prefers-reduced-motion: reduce` — zero activity if the user asked for it.
- Injected once in `layouts/Layout.astro` so it persists across page frames.

### New: TeaserBanner
- `apps/web/src/components/TeaserBanner.astro`
- Slim dismissible gold strip that sits above the player bar inside the
  fixed dock. Red live dot. i18n keys `teaser.liveLabel`, `teaser.message`,
  `teaser.dismiss`.
- Dismiss writes `tkids.teaser.dismissed = "1"` to `localStorage`. Clearing
  that key in devtools re-shows the banner.

### Global marquee
- Rewrote `Marquee.astro` with a 20-item multilingual ticker covering
  EN / zh-TW / ja / ko / fr / it / es / de. Language classes (`lang-zh`,
  `lang-ja`, `lang-ko`) swap in the correct Noto font so CJK doesn't fall
  back to Latin display metrics.

### Crowdfund copy
- Replaced `raised of $— goal` with the new goalTagline
  "crowdfund $3,000 and rock the world" (translated per locale).
- New i18n key: `crowdfund.goalTagline`.
- Goal amount is still rendered dynamically from `/api/funding` — the
  literal `$3,000` is interpolated via `{goal}`.

### FOUT gate
- New inline script at the top of `Layout.astro` adds `fonts-ready` to
  `<html>` once `document.fonts.ready` resolves, or `fonts-late` after a
  1.2s fallback. Hero, nav, and player-dock start at `opacity: 0` and fade
  in once the class lands. Kills the layout-shift pop that happened while
  Unbounded / DM Serif / Noto fonts were still arriving.

### JP/DE hero fix
- `.slogan-manifesto` max-width bumped 560px → 680px; at ≥1200vw it reads
  as a normal 2-line block instead of a cramped column.
- Added Noto Sans JP to the `ja` locale fallback stack; dropped italic for
  CJK (italic Instrument Serif wraps Japanese kana poorly).
- Line-height 1.55 → 1.7 for JP/DE so taller characters don't crowd.

### Content
- Hero description reflow is still a light edit — the copy itself is unchanged.
- Marquee and teaser strings are fresh — review needed on ja/de before
  we re-run the locale QA pass (status markers stay on those JSON files).

## Still mocked / deferred
